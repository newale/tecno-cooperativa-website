# Tecnocoop — sitio web

## Idioma

Todo el contenido del sitio (páginas, documentación, textos de botones, changelog) se escribe en **español chileno**, tratando de **tú**:

- Tuteo, nunca voseo: "puedes", "descarga", "abre", "tú decides" — no "podés", "descargá", "abrí", "vos decidís".
- Vocabulario chileno cuando haya diferencia: "aquí" antes que "acá", "computador" antes que "computadora".
- Los mensajes de commit también van en español.
